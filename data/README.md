# Карты данных как данные

Первоисточник карт атласа. Таблицы на страницах атласа и CSV для скачивания строятся из этих файлов скриптом `scripts/atlas.mjs`, правки вносят сюда, а не в страницы.

```
data/
  sources.yaml        # общий список источников всех карт
  maps/<id>.yaml      # одна карта: паспорт и вопросы со ссылками на источники
  source-checks.yaml  # результат проверки адресов источников (генерируется)
```

```bash
npm run atlas          # проверить данные и пересобрать таблицы и CSV
npm run atlas:check    # только проверить
npm run check-sources  # проверить адреса источников и обновить source-checks.yaml
```

`npm start` и `npm run build` вызывают `npm run atlas` сами. Сгенерированные файлы (`docs/08-atlas/_generated/`, `static/downloads/*.csv`) в git не хранятся.

## sources.yaml

Список источников. Источник описывается один раз, карты ссылаются на него по `id`.

| Поле | Обязательно | Что писать |
|------|:-----------:|------------|
| `id` | да | Латиницей, цифрами и дефисами. Для сайта — домен с дефисами вместо точек: `zakupki-gov-ru`. Для группы — `group-...` |
| `name` | да | Как источник называется на карте |
| `type` | да | `system`, `resource`, `dataset`, `site` или `group` |
| `url` | | Адрес; у группы не указывается |
| `owner` | | Орган власти или организация |
| `aliases` | | Другие названия того же источника — чтобы не завести его дважды |
| `url_note` | | Пояснение к результату проверки адреса, которое скрипт сам не выведет: например, что перенаправление ведёт на сторонний сайт |

Владельцы в текущем списке заполнены по домену в октябре 2026 года и по документам не сверены.

## source-checks.yaml

Файл пишет `scripts/check-sources.mjs`, руками его не правят. Для каждого источника с адресом — результат проверки:

| `result` | Что значит |
|----------|------------|
| `ok` | Сайт открылся |
| `moved` | Перенаправляет на другой домен (`moved_to`) |
| `http-error` | Сайт ответил ошибкой (`http`: 403, 404, 503…) |
| `tls` | Сертификат не принят: просрочен или выдан удостоверяющим центром, которому не доверяют за пределами России |
| `unreachable` | Не ответил: таймаут, отказ в соединении |
| `no-address` | Домен есть, но у него нет адреса — ни у самого домена, ни у www |
| `dns-error` | Ошибка системы доменных имён |
| `nxdomain` | Домена нет |

`nxdomain` не зависит от сети. Остальные результаты зависят: многие российские государственные сайты не открываются из-за рубежа. В поле `network` записано, из какой сети шла проверка (переменная окружения `CHECK_NETWORK`).

## maps/&lt;id&gt;.yaml

| Поле | Обязательно | Что писать |
|------|:-----------:|------------|
| `id` | да | Совпадает с именем файла и с адресом страницы атласа |
| `title` | да | Тема карты |
| `kind` | да | Виды карты: `questions`, `authority`, `product`, `availability` |
| `checked` | да | Месяц и год проверки: `2019-12` |
| `author` | да | Кто составил карту |
| `license` | | Лицензия карты |
| `info_sources` | | Откуда взяты сведения |
| `images`, `downloads` | | Пути к картинкам и файлам для скачивания |
| `notes` | | Расхождения и решения, принятые при переносе карты в данные |
| `questions` | да | Список вопросов |

Вопрос:

| Поле | Обязательно | Что писать |
|------|:-----------:|------------|
| `n` | да | Номер вопроса на исходной карте, по порядку с 1 |
| `text` | да | Текст вопроса |
| `sources` | да | Список пар `{source: <id>, availability: <статус>}` |

`availability` — доступность сведений, отвечающих на этот вопрос, в этом источнике. Один и тот же источник может быть доступен для одного вопроса и недоступен для другого. Значения — по легенде карт 2018–2019 годов:

| Значение | Легенда на карте для печати |
|----------|-----------------------------|
| `available` | Данные доступны |
| `restricted` | Данные доступны с ограничениями |
| `unavailable` | Данные не доступны |
| не указано | Пары нет на карте для печати, доступность не определялась |

Пятиуровневая шкала из главы «Оценка доступности» понадобится при сверке карт: тогда у пары появится поле `status` с датой проверки.
