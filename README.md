# Инвентаризация данных

Книга о том, как выяснить, какие данные есть у организации или государства, и найти данные для задачи: цели и подходы, методы, семь шагов, реестр данных, где искать данные, стандарты описания и страновые практики. Сайт — [datainventory.begtin.tech](https://datainventory.begtin.tech/).

Тексты — в [`docs/`](docs/), начало — [`docs/index.md`](docs/index.md). Сайт собирается Docusaurus.

- Устройство репозитория и команды: [`AGENTS.md`](AGENTS.md)
- План работ: [`PLAN.md`](PLAN.md)
- Прежняя версия книги «Карты данных», её план и ревизии: [`archive/`](archive/)
