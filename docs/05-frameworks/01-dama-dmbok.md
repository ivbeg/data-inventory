# DAMA-DMBOK и управление метаданными

DAMA-DMBOK (Data Management Body of Knowledge) — свод знаний по управлению данными, который выпускает международная ассоциация DAMA. Он делит управление данными на одиннадцать областей с управлением данными (Data Governance) в центре. Отдельной области «инвентаризация» в нём нет: инвентаризация — часть управления метаданными и архитектуры данных. Главный вывод для практики — от разовой описи переходить к постоянному управлению жизненным циклом данных.

## Одиннадцать областей

| Область | Связь с инвентаризацией |
|---------|-------------------------|
| **Управление данными** (Data Governance) — в центре | Кто принимает решения о данных, кто владелец и ответственный; без этого реестру некому поддерживаться |
| **Архитектура данных** | Какие данные есть у организации и как они связаны с процессами и системами — то же, что описывает инвентаризация |
| **Моделирование и проектирование данных** | Схемы и структуры — расширенный состав записи реестра |
| **Хранение данных и операции** | Где физически лежат данные — информационные системы реестра |
| **Безопасность данных** | Режим доступа, чувствительность, персональные данные |
| **Интеграция и интероперабельность** | Обмен данными между системами — цель многих инвентаризаций |
| **Документы и контент** | Данные вне баз: документы, файлы, таблицы |
| **Справочные и мастер-данные** | Справочники и эталонные реестры, которые расходятся между ведомствами |
| **Хранилища данных и бизнес-аналитика** | Аналитика и системы поддержки решений — цель подхода «где найти нужное» |
| **Метаданные** | Описания данных — реестр данных и есть метаданные |
| **Качество данных** | Быстрая проверка качества как часть инвентаризации; подробная оценка и правила — уже управление качеством ([«Качество данных»](../03-process/07-quality.md)) |

## Что из этого следует

- **Инвентаризация — первый шаг управления метаданными.** Реестр данных становится основой каталога метаданных организации.
- **Нужен владелец процесса.** В модели DAMA за метаданные отвечает управление данными: без назначенных владельцев и ответственных реестр устареет. Если владельцев данных десятки, записи ведут они сами по общим правилам, а центр собирает и проверяет — это федеративная модель из Data Mesh ([«Data Mesh»](./03-data-mesh.md#федеративное-управление)).
- **Непрерывность.** Разовая инвентаризация — снимок; управление метаданными — процесс, который обновляет описания вместе с изменениями систем.
