# Зарубежные методики

Готовые методики инвентаризации данных есть в нескольких странах и организациях. Самая развитая — в США, где инвентарь данных ведомства стал требованием закона. Остальные решают более узкие задачи: оценка открытости национальной статистики, инвентаризация данных городов, картирование того, как данные переходят между организациями. Почти все ставят на первое место открытые данные.

## Инвентари данных федеральных ведомств США

- **2013** — меморандум OMB M-13-13 (Open Data Policy) требует от федеральных ведомств вести **корпоративный инвентарь данных** (Enterprise Data Inventory) и публиковать его общедоступную часть. Инвентарь описывают по схеме Project Open Data, публичную часть выкладывают файлом `data.json`, из которого её собирает data.gov.
- **2018** — закон OPEN Government Data Act (раздел II закона Foundations for Evidence-Based Policymaking Act) делает это требование законом: каждое ведомство ведёт полный инвентарь данных, учитывающий все данные, которые оно создаёт, собирает, контролирует или хранит, с описанием переменных и указанием, открыт ли набор.
- **2020** — Счётная палата США (GAO) отмечает, что OMB не выпустило предписанное законом руководство по полным инвентарям.
- **2025** — OMB выпускает меморандум M-25-05 с руководством по второму этапу реализации закона, в том числе по инвентарям.

Главное в американской модели: один инвентарь на всё ведомство, общий стандарт описания и разделение полного реестра и его общедоступной части. Для публикации используется система inventory.data.gov.

## Open Data Inventory (ODIN)

Методика организации Open Data Watch для оценки национальных статистических служб: насколько полно и открыто они публикуют данные по социальным, экономическим и экологическим показателям. Это инвентаризация со стороны пользователя — «где найти нужное» для статистики, — с оценками по охвату и открытости.

## GovEx Data Inventory

Руководство Центра государственного совершенства Университета Джонса Хопкинса (GovEx) для городов: зачем городу инвентарь данных, как его собрать, какие поля вести и как связать с программой открытых данных. Практический образец для муниципального уровня.

## Картирование экосистем данных ODI

Методика Open Data Institute (Mapping data ecosystems): как изобразить участников, потоки данных и ценность, которую они создают. Ближе всего к [картам данных](../02-approaches/04-data-maps.md) от продукта: помогает понять, кто от кого получает данные и где связи рвутся.

## Что взять

| Методика | Что взять |
|----------|-----------|
| США | Обязательный инвентарь, единая схема описания, разделение полного и публичного реестра |
| ODIN | Оценку охвата и открытости с позиции пользователя |
| GovEx | Пошаговое руководство и состав полей для города |
| ODI | Картирование связей между участниками |
