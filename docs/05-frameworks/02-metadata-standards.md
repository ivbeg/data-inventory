# Стандарты описания

Реестр данных, описанный по стандарту, можно обменивать с каталогами и порталами, собирать автоматически и сравнивать с реестрами других организаций. Для государственных данных главные стандарты — словарь W3C DCAT и его европейский профиль DCAT-AP; в США — схема Project Open Data. Наборы высокой ценности ЕС показывают, какие данные государство обязано публиковать в первую очередь. Атрибуты реестра стоит сразу сопоставить с одним из стандартов.

## Стандарты

| Стандарт | Что это | Где применяется |
|----------|---------|-----------------|
| **DCAT** (Data Catalog Vocabulary) | Словарь W3C для машиночитаемого описания каталогов, наборов данных и их распространения. Версия 3 — рекомендация W3C от 22 августа 2024 года | Каталоги и порталы по всему миру |
| **DCAT-AP** | Европейский профиль применения DCAT: какие свойства обязательны и какие словари использовать | Порталы открытых данных стран ЕС и европейский портал data.europa.eu |
| **Project Open Data Metadata Schema v1.1** | Схема описания наборов для федеральных ведомств США; описания публикуются файлом `data.json` | Инвентари ведомств США и каталог data.gov |
| **Наборы высокой ценности** (High Value Datasets) | Исполнительный регламент ЕС 2023/138: шесть категорий данных, которые государственные органы публикуют бесплатно, в машиночитаемом виде, через программный интерфейс и массовой выгрузкой | Государства — члены ЕС |

Шесть категорий наборов высокой ценности: геопространственные данные; наблюдение Земли и окружающая среда; метеорологические данные; статистика; компании и владение компаниями; мобильность.

## Сопоставление с реестром

| Атрибут реестра | DCAT | Project Open Data v1.1 |
|-----------------|------|------------------------|
| Уникальный идентификатор | `dct:identifier` | `identifier` |
| Наименование | `dct:title` | `title` |
| Описание | `dct:description` | `description` |
| Ответственный и контакты | `dcat:contactPoint` | `contactPoint` |
| Периодичность обновления | `dct:accrualPeriodicity` | `accrualPeriodicity` |
| Режим доступа | `dct:accessRights` | `accessLevel` (public, restricted public, non-public) |
| Ссылка для выгрузки | `dcat:downloadURL` у распространения | `distribution` → `downloadURL` |
| Формат распространения | `dct:format`, `dcat:mediaType` | `format`, `mediaType` |
| Дата публикации | `dct:issued` | `issued` |
| Дата последнего изменения | `dct:modified` | `modified` |
| Отметка о контроле качества | отдельного свойства нет — словарь качества W3C DQV | `dataQuality` |
| Условия использования | `dct:license` | `license` |
| Организация-владелец | `dct:publisher` | `publisher` |

Схема Project Open Data хорошо подходит для подхода «чем владеем»: в ней есть поле `accessLevel` для закрытых наборов, и один файл описывает и публичную, и непубличную часть инвентаря.

## Что выбрать

- **Для публичного каталога** — DCAT или национальный профиль DCAT, если он есть: тогда каталог собирают агрегаторы и поисковики.
- **Для внутреннего реестра** — тот же словарь: проще открыть часть реестра без переделки. Обзор по Казахстану рекомендует порталу data.egov.kz перейти на DCAT-AP, чтобы описания стали совместимы с международными каталогами.
- **Для приоритетов открытия** — категории наборов высокой ценности ЕС как ориентир, даже вне ЕС.
