# Глоссарий

## Термины

**Анализ разрывов** (gap-анализ) — сопоставление задач с найденными данными: чего нет, что закрыто, что непригодно. → [Семь шагов](../03-process/01-steps.md#5-сопоставить-цели-с-данными)

**Веб-архив** — сервис, который сохраняет копии сайтов с датами: Internet Archive, национальные архивы веба. → [Исчезнувшие системы и веб-архивы](../04-sources/06-legacy.md)

**Владелец** — организация, которая ведёт набор данных или систему и отвечает за них. → [Владельцы и полномочия](../03-process/03-owners-and-mandates.md)

**Группа источников** — несколько однотипных источников, записанных одной строкой, когда перечислить их поштучно невозможно. → [Реестр данных](../03-process/05-registry.md#одинаковая-подробность)

**Данные как продукт** — принцип Data Mesh: данные оформляют с документацией, программным интерфейсом и обязательствами по качеству. → [Data Mesh](../05-frameworks/03-data-mesh.md)

**Информационная система** — базы данных вместе с программами и оборудованием, которые их обрабатывают. → [Что инвентаризируют](../01-basics/04-what-is-inventoried.md)

**Инвентаризация данных** — систематическое выявление и описание данных: какие наборы есть, где хранятся, кто владелец, на каком основании собираются, насколько доступны и качественны. → [Что такое инвентаризация данных](../01-basics/01-what-is-data-inventory.md)

**Интеллект-карта** (mindmap) — схема в виде дерева от центрального понятия. → [Интеллект-карты, доски и таблицы](../06-tools/02-mindmaps-and-boards.md)

**Карта данных** — результат подхода «где найти нужное»: вопросы, источники ответов и их доступность. → [Карты данных](../02-approaches/04-data-maps.md)

**Каталог данных** — сервис, который описывает наборы данных и помогает их найти и получить. → [Что такое инвентаризация данных](../01-basics/01-what-is-data-inventory.md#чем-инвентаризация-отличается-от-соседних-понятий)

**Каталог метаданных** — система, которая собирает описания данных из баз и хранилищ организации: OpenMetadata, DataHub, Apache Atlas. → [От таблицы до каталога метаданных](../06-tools/01-from-spreadsheet-to-catalog.md)

**Набор данных** — совокупность однотипных сведений, которую можно описать и передать целиком. → [Что инвентаризируют](../01-basics/04-what-is-inventoried.md)

**Наборы высокой ценности** (High Value Datasets) — шесть категорий данных, которые государственные органы ЕС публикуют бесплатно, в машиночитаемом виде и через программный интерфейс. → [Стандарты описания](../05-frameworks/02-metadata-standards.md)

**Обмен данными** (data sharing) — предоставление данных другим организациям, в том числе бизнесу, на определённых условиях. → [Зачем: цели](../01-basics/02-goals.md)

**Озеро данных** — хранилище, куда загружают данные из разных систем в исходном виде для аналитики. → [Результат и поддержка](../03-process/08-result-and-upkeep.md)

**Основание** — закон, полномочие или договор, ради которого собирают данные. → [Владельцы и полномочия](../03-process/03-owners-and-mandates.md)

**Полномочие** — обязанность органа власти, закреплённая в законе или положении об органе. → [Владельцы и полномочия](../03-process/03-owners-and-mandates.md)

**Реестр данных** (инвентарь) — результат инвентаризации: по записи на каждый набор с владельцем, доступом и датой. → [Реестр данных](../03-process/05-registry.md)

**Режим доступа** — можно ли получить данные и на каких условиях: открытые данные, неструктурированные сведения, с ограничениями, закрыто, не установлено. → [Доступ и ограничения](../03-process/06-access.md)

**Ресурс** — совокупность сведений внутри системы: реестр, база, перечень. → [Что инвентаризируют](../01-basics/04-what-is-inventoried.md)

**Федеративное управление** — общие стандарты и политики при децентрализованном исполнении. → [Data Mesh](../05-frameworks/03-data-mesh.md)

**Data-first** — проектирование систем от данных, а не от интерфейсов. → [Принципы](../01-basics/03-principles.md)

## Сокращения и названия

**DAMA-DMBOK** — свод знаний по управлению данными ассоциации DAMA International. → [DAMA-DMBOK](../05-frameworks/01-dama-dmbok.md)

**DCAT, DCAT-AP** — словарь W3C для описания каталогов и наборов данных и его европейский профиль. → [Стандарты описания](../05-frameworks/02-metadata-standards.md)

**Data Mesh** — подход к архитектуре данных с владением у доменных команд. → [Data Mesh](../05-frameworks/03-data-mesh.md)

**EDI** (Enterprise Data Inventory) — инвентарь данных федерального ведомства США. → [Зарубежные методики](../05-frameworks/04-international-practice.md)

**ODIN** (Open Data Inventory) — методика Open Data Watch для оценки открытости национальной статистики. → [Зарубежные методики](../05-frameworks/04-international-practice.md)

**Project Open Data** — политика и схема описания данных федеральных ведомств США. → [Стандарты описания](../05-frameworks/02-metadata-standards.md)

**ГИС** — государственная информационная система. → [Государственные данные](../04-sources/02-government.md)

**ГБД** (Казахстан) — государственная база данных: физические лица, юридические лица, регистр недвижимости и другие. → [Казахстан](../07-countries/01-kazakhstan.md)

**НПА** — нормативный правовой акт.

**СППР** — система поддержки принятия решений.

**ФГИС КИ** (Россия) — федеральная государственная информационная система координации информатизации, оператор — Минцифры России. → [Россия](../07-countries/02-russia.md)
