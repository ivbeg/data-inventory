# Семь методов

Ни один метод не находит всех данных. Опросы владельцев не видят того, что владелец забыл; реестры систем — того, что в них не попало; поиск по сайтам — закрытых систем. Поэтому методы сочетают, и выбор зависит от цели и от того, чьи данные ищут.

## Методы

| Метод | Что это | Что находит лучше всего |
|-------|---------|-------------------------|
| **Опросы владельцев** | Анкеты и интервью с сотрудниками, которые ведут системы и данные | Свои данные организации, включая неочевидные: таблицы, выгрузки, справочники |
| **Опросы экспертов** | Консультации отраслевых специалистов, ассоциаций, сообщества | Какие данные критичны для отрасли и где они на самом деле лежат |
| **Специализированный поиск** | Поиск по наборам данных в поисковиках и агрегаторах: Dateno, Google Dataset Search, OpenAIRE | Опубликованные наборы в тысячах каталогов сразу |
| **Кабинетные исследования** | Ручной анализ сайтов органов власти, порталов, открытых информационных систем, документов | Публичные системы и разделы данных, отчёты, публикации |
| **Инвентаризация информационных систем** | Анализ реестров государственных систем, их паспортов, технических заданий и госконтрактов | Системы и ресурсы в них, в том числе закрытые |
| **Анализ полномочий** | Чтение положений об органах власти и отраслевых законов: если ведомство обязано выполнять функцию, оно создаёт связанные с ней данные | Данные, которые должны существовать по закону, — даже если их нет в реестрах |
| **Поиск по аналогии** | Сравнение с другими странами, регионами, ведомствами: если где-то такие данные собирают и публикуют, значит, и у нас их кто-то должен собирать | Пробелы и неочевидные источники |

## Какой метод для каких данных

Данные бывают государственные, общественные и коммерческие ([«Три слоя данных»](../04-sources/01-three-layers.md)), и для каждого слоя работают свои методы.

| Слой | Методы |
|------|--------|
| **Государственные** | Анализ полномочий; опросные листы; анализ текстов госконтрактов и государственных заданий; реестры государственных информационных систем; сфокусированный поиск по официальным сайтам |
| **Общественные** | Сфокусированный поиск общественных проектов; каталоги наборов данных (например, Awesome Public Datasets); консультации экспертов и сообщества — форумы, чаты, сайты вопросов и ответов; поиск в каталогах научных данных (re3data.org) |
| **Коммерческие** | Консультации экспертов и профильных ассоциаций; целевые запросы к компаниям |

## Какой метод для какого подхода

- **«Чем владеем»:** опросы владельцев, инвентаризация систем, анализ полномочий. Кабинетные исследования — чтобы проверить ответы владельцев.
- **«Где найти нужное»:** кабинетные исследования, специализированный поиск, эксперты, поиск по аналогии. Анализ полномочий — чтобы понять, у кого искать.

## Порядок, который работает

1. **Анализ полномочий** — даёт список владельцев и того, что у них должно быть.
2. **Реестры систем и кабинетные исследования** — показывают, что есть на самом деле.
3. **Специализированный поиск** — находит опубликованное.
4. **Опросы владельцев и экспертов** — закрывают пробелы и проверяют найденное.
5. **Поиск по аналогии** — показывает, чего не хватает.

Каждый шаг можно ускорить с помощью ИИ: анализ полномочий по нормативным актам, поиск наборов по сайтам и описание найденного ([«ИИ в инвентаризации»](./03-ai.md)).
