# Два подхода

Инвентаризацию ведут с одной из двух сторон. **«Понять, чем владеем»** — опись собственных данных: начинают с владельца и его систем. **«Понять, где найти нужное»** — поиск данных под задачу: начинают с вопросов и ищут ответы везде, в том числе у других организаций. Подход выбирают по цели ([«Зачем: цели»](../01-basics/02-goals.md)), и от него зависят методы, источники и результат.

## Сравнение

| | Чем владеем | Где найти нужное |
|---|---|---|
| **С чего начинают** | С владельца: организация, ведомство, отрасль | С задачи и вопросов к данным |
| **Для чего** | Навести порядок в сборе данных, найти дубли, выделить чувствительные данные, подготовить открытие и обмен данными | Системы поддержки принятия решений, сложные отраслевые проекты, новые продукты |
| **Где ищут** | Свои системы, реестр информационных систем, документы о системах | Государственные, общественные и коммерческие источники — [три слоя данных](../04-sources/01-three-layers.md) |
| **Главные методы** | Опросы владельцев, инвентаризация систем, анализ полномочий | Кабинетные исследования, поиск наборов данных, эксперты, поиск по аналогии |
| **Глубина описания** | До ресурсов и полей, с ответственными и режимом доступа | До источника и условий доступа |
| **Результат** | Реестр данных, внутренний каталог | Карта данных, список источников для проекта |
| **Типичная ловушка** | Опись ради описи: всё перечислено, ни на один вопрос не отвечено | Список чужих сайтов без владельцев и без проверки, что данные там есть |

## Чем владеем

Подход для организации, которая хочет знать свои данные: министерства, региона, компании. Его приоритет — то, что требует особого обращения, прежде всего персональные данные. Начинают с перечня систем и их владельцев, затем описывают ресурсы в каждой системе и наборы, которые можно передавать или публиковать. Основные инструменты — [опросные листы](../03-process/04-questionnaires.md) и реестр информационных систем.

Результат — [реестр данных](../03-process/05-registry.md), который становится основой каталога, программы открытия данных или межведомственной интеграции.

## Где найти нужное

Подход для задачи, которой не хватает данных: аналитики, продукта, исследования. Начинают с вопросов, которые задают руководители или аналитики, и для каждого ищут источники — у государства, в общественных проектах, у компаний. Данные чужие, поэтому опросы владельцев здесь почти не работают: основные методы — кабинетные исследования, поиск наборов данных и консультации экспертов ([«Семь методов»](./02-methods.md)).

Результат часто оформляют как [карту данных](./04-data-maps.md): вопросы, источники и их доступность.

## Когда подходы сочетают

- **Перед открытием данных** ведомство описывает свои данные («чем владеем») и сверяет их с тем, что востребовано у пользователей («где найти нужное»).
- **Для проактивных услуг** государство сначала ищет, где лежат нужные сведения о человеке или организации, затем описывает эти системы до полей.
- **Для отраслевой аналитики** находят источники под вопросы, а затем подробно описывают несколько ключевых систем одного ведомства.
