# Интеллект-карты, доски и таблицы

Интеллект-карта хороша, чтобы показать результат и провести мозговой штурм, доска с колонками — чтобы обсудить доступность данных по ведомствам, таблица — чтобы вести реестр. Сведения живут в таблице, картинку строят из неё: тогда смена инструмента не означает потерю результата.

![Пример подготовки интеллект-карты в онлайн-сервисе](/img/tools/miro-mindmap.gif)

## Чем рисовать

| Инструмент | Что это | Когда удобен |
|------------|---------|--------------|
| **Xmind** | Настольное приложение для интеллект-карт | Карта для печати и показа; карты атласа нарисованы в нём |
| **Freeplane** | Настольное приложение с открытым кодом | Бесплатно и без облака |
| **markmap** | Превращает список в Markdown в интерактивную интеллект-карту | Карта хранится как текст рядом с документацией |
| **Mermaid** | Схемы из текстового описания, в том числе интеллект-карты | Схемы на сайте или в репозитории: так нарисованы схемы этой книги |
| **Онлайн-доски** | Совместные доски со стикерами и колонками | Обсуждение в распределённой команде |
| **Стикеры на стене** | Бумага, маркерная доска | Мозговой штурм в одной комнате |

:::warning[Облачные сервисы и доступность]
Облачный сервис может закрыться для пользователей целой страны. По сообщениям СМИ, Miro в сентябре 2024 года отключил платные аккаунты пользователей из России и Беларуси, а с 15 октября 2026 года закрыл доступ с российских IP-адресов для всех тарифов. Перед выбором сервиса проверьте, доступен ли он всем участникам, и храните сведения в своей таблице.
:::

## Доска с колонками

Для карты доступности: колонка — ведомство, карточка — система или набор, цвет — режим доступа ([«Доступ и ограничения»](../03-process/06-access.md)), на обороте — основание и дата. На обсуждении участники видят, у кого больше закрытых систем, и перекладывают карточку, если статус неверный.

![Шаблон визуализации доступности систем по ведомствам](/img/map-types/template-availability.webp)

## Рабочая таблица

Для реестра удобнее три листа:

| Лист | Строка | Колонки |
|------|--------|---------|
| **Наборы** | один набор или источник | идентификатор, наименование, тип, владелец, основание, адрес, синонимы, режим доступа, дата проверки |
| **Вопросы или задачи** | один вопрос | номер, текст, задача |
| **Связи** | пара «вопрос — набор» | номер вопроса, идентификатор набора, доступ для этой задачи, основание, дата |

Для подхода «чем владеем» хватает первого листа с [14 атрибутами](../03-process/05-registry.md); второй и третий нужны подходу «где найти нужное».

## Как не потерять результат

- **Одна строка — одна вещь**: не пишите несколько наборов в одну ячейку.
- **Значения из списка** для режима доступа и типа — иначе появятся «открыто», «откр.» и «да».
- **Даты в одном формате**.
- **Храните исходник**, а не только экспорт в картинку: у карт атласа 2018–2019 годов исходников не сохранилось, и их пришлось переносить в данные с картинок.
- **Храните версии** — копии с датой или репозиторий git.
