# Три слоя данных

Данные для любой задачи лежат в трёх слоях. **Государственные** — в системах органов власти: их много, часть открыта, часть регламентирована законами, качество обычно невысокое. **Общественные** — в открытых проектах, научных репозиториях, у международных организаций: открыты, но тоже часто неидеальны. **Коммерческие** — у банков, операторов связи, бюро кредитных историй: обычно высокого качества, но доступны только по соглашениям. Инвентаризация «где найти нужное» проходит по всем трём; инвентаризация «чем владеем» в государстве — в основном по первому.

## Сравнение

| | Государственные | Общественные | Коммерческие |
|---|---|---|---|
| **Доступ** | Открытые и регламентированные нормативными актами | Открытые | По специальным соглашениям |
| **Качество** | Обычно невысокое | Обычно невысокое | Обычно высокое |
| **Где искать** | Порталы открытых данных, реестры информационных систем, официальные сайты, госзакупки, нормативные акты, статистика | Общественные проекты, Wikidata и OpenStreetMap, научные репозитории, международные организации, подборки наборов | Операторы связи, банки, бюро кредитных историй, отраслевые компании |
| **Методы** | Анализ полномочий, реестры систем, анализ контрактов, опросы, поиск по сайтам | Поиск проектов и каталогов, эксперты и сообщество | Эксперты, ассоциации, целевые запросы к компаниям |
| **Глава** | [Государственные данные](./02-government.md) | [Общественные данные](./03-public.md) | [Коммерческие данные](./04-commercial.md) |

Оценки качества — обобщение, а не правило: бывает отличная государственная статистика и плохие коммерческие данные. Проверяют каждый набор ([«Качество данных»](../03-process/07-quality.md)).

## Пример: Казахстан

В Казахстане три слоя выглядят так:

- **государственные данные** — портал открытых данных data.egov.kz, базовые государственные базы данных (физические лица, юридические лица, регистр недвижимости, электронное лицензирование), Бюро национальной статистики stat.gov.kz, единая платформа закупок zakup.gov.kz (прежде goszakup.gov.kz), правовая система «Әділет» adilet.zan.kz;
- **общественные данные** — экосистема Викимедиа (Wikidata, Википедия) и построенная на Википедии DBpedia, OpenStreetMap, порталы международных организаций (Всемирный банк, ООН, ВОЗ, ОЭСР), научные репозитории (re3data.org). Международные показатели расходятся с национальными по методике: население Казахстана у Всемирного банка больше, чем у Бюро национальной статистики ([«Общественные данные»](./03-public.md#международные-организации));
- **коммерческие данные** — данные банков, операторов связи, финтеха, которые можно получать в рамках обмена данными с отраслью.

Подробнее — в главе [«Казахстан»](../07-countries/01-kazakhstan.md).

## С чего начинать

1. **Государственные данные** — по [анализу полномочий](../03-process/03-owners-and-mandates.md): он даёт владельцев и то, что у них должно быть.
2. **Поиск наборов данных** — по всем слоям сразу: поисковики собирают описания из тысяч каталогов ([«Поиск наборов данных»](./05-dataset-search.md)).
3. **Общественные и коммерческие** — для того, чего не нашлось у государства, и для проверки государственных данных.
