# Поиск наборов данных

Если неизвестно, где опубликован набор, его ищут не по порталам по очереди, а в поисковике по наборам данных: такие поисковики собирают описания из тысяч каталогов — государственных, научных, международных. Это самый быстрый метод для опубликованных данных и бесполезный для неопубликованных. Найденный набор ведёт к каталогу и владельцу, а через них — к системе, из которой он выгружен.

## Инструменты

| Инструмент | Что ищет |
|------------|----------|
| [Dateno](https://dateno.io/) | Наборы данных из порталов открытых данных, геопорталов, научных репозиториев и статистических служб по всему миру |
| [Google Dataset Search](https://datasetsearch.research.google.com/) | Страницы наборов данных с разметкой schema.org |
| [OpenAIRE Explore](https://explore.openaire.eu/) | Научные публикации и наборы данных исследований |
| [re3data.org](https://www.re3data.org/) | Каталог научных репозиториев данных — где искать по дисциплине |
| [Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets) | Подборка открытых наборов по темам |
| Национальные порталы открытых данных | Наборы одной страны — data.egov.kz, data.gov, data.europa.eu и другие |

Dateno — проект автора книги; как устроены каталоги, по которым ищут такие поисковики, и почему одни каталоги находятся легко, а другие нет, — в книге [«Каталоги данных»](https://datacatalogs.begtin.tech/).

## Как использовать

1. **Искать по теме и по стране** — на языке страны и по-английски: описания наборов бывают на обоих.
2. **От набора — к владельцу.** У найденного набора смотрят каталог и организацию, которая его опубликовала.
3. **От владельца — к системе.** По описанию набора и сайту владельца ищут ресурс и систему, из которой он выгружен.
4. **Записать набор в реестр** с типом «опубликованный набор» и связать с ресурсом.
5. **Посмотреть дату** последнего обновления.

## Ограничения

- Поисковики видят только опубликованное и только то, что каталоги отдают в машиночитаемом виде.
- Описания бывают неполными, а ссылки — устаревшими.
- Одни и те же наборы встречаются в нескольких каталогах — нужна проверка на дубли.
