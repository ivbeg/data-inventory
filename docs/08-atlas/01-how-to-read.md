# Как читать атлас

Атлас — пример результата инвентаризации по подходу «где найти нужное»: четыре отраслевые [карты данных](../02-approaches/04-data-maps.md), составленные в 2018–2019 годах по российским источникам, — государственные финансы, нефть и газ, здравоохранение, образование. Все они построены от вопросов: на каждый вопрос дан список источников, и у каждого источника отмечено, доступны ли в нём сведения. Карты хранятся как данные, таблицы на страницах атласа строятся из них. Доступность — по легенде 2018–2019 годов и с тех пор заново не проверялась.

## Легенда

На картах для печати доступность отмечена ромбами трёх цветов. В таблицах атласа те же цвета показаны кружками.

| Отметка | Легенда исходной карты | Что это значит по [шкале доступности](../03-process/06-access.md#шкала) |
|---------|------------------------|-----------------------------------------------------|
| <span className="avail avail--available">●</span> | Данные доступны | открытые данные или неструктурированные сведения — карты 2018–2019 годов эти статусы не различали |
| <span className="avail avail--restricted">●</span> | Данные доступны с ограничениями | с ограничениями: регистрация, плата, договор |
| <span className="avail avail--unavailable">●</span> | Данные не доступны | закрыто — или нет внешнего доступа, а основание не установлено |
| <span className="avail avail--unknown">○</span> | — | доступность не указана: пары нет на карте для печати |

На интеллект-картах источники подчёркнуты цветными линиями. Красные и жёлтые линии в основном совпадают с ромбами карт для печати, но легенды у интеллект-карт нет, а доступные источники подчёркнуты по-разному: на карте здравоохранения — бирюзовым, тёмно-зелёным и синим. Поэтому доступность в атласе взята с карт для печати, где легенда есть.

Чтобы перевести карту на пятиуровневую шкалу, каждую пару нужно проверить заново по [порядку проверки](../03-process/06-access.md#порядок-проверки). Это задача следующей версии атласа.

## Как устроена страница карты

Все страницы атласа устроены одинаково:

1. **Паспорт** — тема, вид карты, дата проверки, число вопросов и источников, откуда сведения, автор, лицензия, ссылка на данные.
2. **Вопросы и источники** — главная таблица карты.
3. **Источники карты** — каждый источник один раз, с владельцем, номерами вопросов, на которые он отвечает, и результатом проверки адреса.
4. **Визуализации** — интеллект-карта и карта для печати.
5. **Файлы для скачивания** — картинка, PDF, таблица CSV, интеллект-карта в Markdown и в формате FreeMind и файл данных YAML. Таблица и интеллект-карты построены из файла данных; как их открыть, объяснено в главе [«Интеллект-карты, доски и таблицы»](../06-tools/02-mindmaps-and-boards.md#картинка-из-таблицы).
6. **Что изменилось** — история карты и решения, принятые при её переносе в данные.

Как устроен файл данных, рассказано в главе [«Реестр как данные»](../06-tools/03-registry-as-data.md).

## Адреса источников в октябре 2026 года

23 октября 2026 года все адреса источников атласа проверены скриптом: есть ли домен и что отвечает сайт. Результат для каждого источника — в последней колонке таблицы «Источники карты» на странице карты, сводка — ниже.

<SummaryChecks />

Как читать результат:

- **«домена нет»** — домен больше не зарегистрирован. Это надёжный признак: так отвечает система доменных имён в любой стране. У 28 источников атласа адреса 2018–2019 годов исчезли совсем — среди них поддомены Минздрава, Минэкономразвития и сайтов на edu.ru.
- **«перенаправляет»** — сайт переехал: rosminzdrav.ru — на minzdrav.gov.ru, roszdravnadzor.ru — на roszdravnadzor.gov.ru, nalog.ru — на nalog.gov.ru. Для пары адресов перенаправление ведёт на сторонний сайт — это отмечено в таблице.
- **«не ответил», «ошибка 403», «ошибка сертификата»** — результат зависит от сети. Проверка шла из сети, где многие российские государственные сайты не открываются, а часть из них использует сертификаты, которые не принимают браузеры за пределами России. Такие адреса нужно перепроверить из российской сети, прежде чем считать их закрытыми.

Проверка адреса не заменяет [проверку доступности](../03-process/06-access.md): открывающийся сайт ещё не значит, что на нём есть нужные данные.
